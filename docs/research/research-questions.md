# Research questions (planning)

These are the questions the project should be able to answer after experiments. No numbers until real runs exist.

## RQ1

Can the framework automatically identify common IoT security weaknesses?

## RQ2

Can an IoT-specific dynamic risk score represent contextual IoT risk better than a static vulnerability score alone?

## RQ3

Can ML assist in prioritizing IoT security risk?

## RQ4

Can explainable AI make risk decisions understandable?

## Metrics (to measure later, not invent)

Scanner: detection rate, false positives, false negatives, scan time.

ML: accuracy, precision, recall, F1, ROC-AUC, confusion matrix.

Risk scoring: correlation with expert labels, ranking quality, stability, sensitivity, before/after remediation change.
